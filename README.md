# AnuTek Solutions

Frontend-only technical showcase built with Next.js, TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

Import this repository into Vercel, or run `vercel` from the project directory. Vercel detects the Next.js framework automatically and uses `npm run build`.

No environment variables, database, authentication or payment configuration are required.
